MacStarStacker – インストールと初回起動ガイド

MacStarStackerをご利用いただきありがとうございます。 本アプリは個人開発プログラムとして直接配布されているため、初回起動時にmacOSのセキュリティ機能（Gatekeeper）によって起動がブロックされる場合があります。

以下の手順に沿って、インストールと初回起動を行ってください。

📥 1. インストール手順

  1. 配布された MacStarStacker.dmg ファイルをダブルクリックして開きます。
  2. 小さなウィンドウが表示されます。
  3. 左側にある星のアイコン（MacStarStacker.app）を、右側にある青いフォルダアイコン（Applications）の上にドラッグ＆ドロップします。
  4. これでインストールは完了です。DockのLaunchpadや、「アプリケーション」フォルダからアプリを探すことができます。
  5. （インストール後、デスクトップにある「MacStarStacker」の白いドライブアイコンは、右クリックして「取り出す」を選択して構いません。）

🛡 2. 初回起動時のセキュリティ解除手順

個人配布のアプリ（Appleの公証を受けていないアプリ）であるため、普通にダブルクリックすると「開発元を検証できないため開けません」といった警告メッセージが表示され、開くことができません。

初回のみ、以下のAまたはBのいずれかの方法でアプリを開いてください。（2回目以降は通常通りダブルクリックで起動できます）

A. 【推奨】右クリックから開く方法（最も簡単です）

  1. 「アプリケーション」フォルダを開き、MacStarStacker のアイコンを見つけます。
  2. アイコンを右クリック（またはキーボードの Control キーを押しながらクリック）します。
  3. 表示されたメニューから 「開く」 をクリックします。
  4. 「開発元を検証できないため開けません」という警告が出ますが、今回は右下に 「開く」 というボタンが表示されます。
  5. 「開く」 をクリックすると、アプリが正常に起動します。

B. 「システム設定」から許可する方法

もし上記の方法で「開く」ボタンが表示されない場合は、こちらの方法をお試しください。

  1. 通常通りアプリをダブルクリックし、「開けません」のエラーが出たら「OK」または「キャンセル」を押して閉じます。
  2. 画面左上のAppleメニュー（）から 「システム設定...」 を開きます。
  3. 左側のメニューから 「プライバシーとセキュリティ」 を選択し、下の方へスクロールします。
  4. 「セキュリティ」の項目に、「"MacStarStacker"は開発元を確認できないため、使用がブロックされました。」というメッセージが表示されています。
  5. その横にある 「このまま開く」 ボタンをクリックします。
  6. Macのログインパスワード（またはTouch ID）を求められたら入力します。
  7. 最後に「開く」ボタンをクリックすると、アプリが起動します。

C. ターミナルから一括で許可する方法（詳細設定）

もしUIからの操作が面倒な場合や、他のファイルも同時にブロックされている場合は、「ターミナル」アプリからコマンドでセキュリティ制限（Quarantine属性）を解除できます。

  1. Macの「アプリケーション」 > 「ユーティリティ」内にある ターミナル を開きます（Spotlight検索で「ターミナル」と検索してもOKです）。
  2. 開いた黒い画面（または白い画面）に、以下のコマンドをコピー＆ペーストしてください。半角スペースが入っていることに注意してください。
    xattr -cr /Applications/MacStarStacker.app

    ※もしMacStarStacker.appをアプリケーションフォルダ以外（デスクトップなど）にインストールした場合は、/Applications/MacStarStacker.app の部分を実際のパスに書き換えるか、xattr -cr （最後に半角スペース）と入力した後にアプリのアイコンをターミナルにドラッグ＆ドロップしてください。

  3. Enter（Return） キーを押して実行します。（特に完了メッセージは出ずに次の行へ進めば成功です）。
  4. 以降は、アプリアイコンをダブルクリックするだけで通常起動できるようになります。

💡 ヒント 一度この操作を行えば、macOSが安全なアプリとして記憶するため、次回からは通常通りアイコンをダブルクリックするだけで起動できるようになります。
