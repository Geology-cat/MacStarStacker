# 星景写真用スタッキングMacアプリ 仕様書

## 1. アプリ概要
本アプリは、Windows用ソフトウェア「Sequator」のような、星景写真に特化した画像スタッキング（コンポジット）をMac環境で行うためのアプリケーションです。
星の日周運動を追尾しながら、地上の風景はブレさせずに固定して合成する「空と地上の分離」機能を備え、ノイズの少ないクリアな星景写真を生成することを目的とします。

## 2. 目的
- Mac環境において、手軽かつ高速・高品質な星景写真のスタッキングを実現する。
- 複雑な設定を極力減らし、直感的なUIで初心者から上級者まで幅広く利用できるようにする。

## 3. 主要機能要件

### 3.1 画像の読み込み・管理
- **対応フォーマット**: 各社RAW（Sony `.arw`, Canon `.cr2`/`.cr3`, Nikon `.nef`, Fujifilm `.raf`, Olympus/OM `.orf`, Panasonic `.rw2`, Pentax `.pef`, Adobe `.dng` 等）、TIFF、FITS、JPEG、PNG
- **メタデータ自動解析**: RAWファイルからカメラ機種名、レンズメーカー、レンズモデル名、焦点距離、F値、ISO、露出時間、カラーマトリクス情報を自動抽出
- **入力画像の種類**:
  - ベース画像（基準合わせの基準となるフレーム）
  - 星空画像（ライトフレーム）
  - ノイズ除去用キャリブレーション画像（ダークフレーム、フラットフレーム、バイアスフレーム）
- **ファイルリスト管理**: ドラッグ＆ドロップでのファイル追加、リストからの削除・順番の確認機能、各ファイルのレンズ情報サブタイトル表示

### 3.2 スタッキング（合成）処理
- **アライメント機能**:
  - 星を自動検出し、各フレーム間の星の位置ズレを算出して補正する機能
  - 回転と平行移動だけではなく、基準画像に対する歪みなども補正して、周辺部までスタッキング後の星が点像になるように高精度にアライメントする
- **スタッキングモード**:
  - **星と風景の合成（空と地上の分離）**: 空の領域は星の動きに合わせてスタッキングし、地上の領域は風景を固定してスタッキングする（本アプリのコア機能）
  - **星だけの合成**: 星のみを基準にしてスタッキング（赤道儀を使った撮影や、星空のみの写真向け）
  - **スタートレイル（星の軌跡）**: 比較明合成による星の軌跡の作成
    - **飛行機・人工衛星の光跡自動除去 (Auto Trail Removal)**:
      - 2K解析、前後最大6枚の時間中央値・MAD、画像別ノイズ床、直線検出（Hough Lines）、線上支持率・周辺輝度差・色差候補解析により、微弱な局所的人工光跡を候補化
      - 厳密な画素閾値を下回る長い線は低閾値マスクと線方向の輝度積算、短く途切れた線は局所コントラストの線分検出で補完する。どちらも現在フレームと時間差分の中心線・側帯を比較し、星像の偶然の並びや全フレームに残る地形境界を除外
      - 清浄画像では1px幅・背景との差7階調の線を保持し、高ノイズ画像では信頼できる最短線長を自動調整して短い星像・圧縮模様の誤検出を抑制
      - **流星候補の保護レビューUI**: 端点輝度の非対称性を手がかりに候補を表示し、最終的な「残す／消す」はユーザーが確認・選択。初期内容領域は最大720×440pt、最小640×380ptを保ちながら画面内でユーザーが拡大でき、検出ハイライトのON/OFFにより元画像と比較可能
      - 前後フレームの平均とマスク境界のフェザーによる修復を行い、露出変動によるフレーム全体の誤消去を抑制
- **合成アルゴリズム**:
  - 平均値（Average）、中央値（Median）、比較明合成（Compare Bright / Star Trails）
  - 航空機や人工衛星の軌跡、流星などの候補を抑制するための時間中央値・MADによる外れ値検出、および時間的なフレーム補修

### 3.3 エリア指定（マスク）機能
- **手動マスク**: 「空と地上を分けて合成」をONにした場合だけブラシを有効化し、画像プレビュー上をなぞって空と地上を塗り分ける。余白・ズーム・パンを含む表示座標を元画像のピクセル座標へ変換し、ポインタ位置と描画位置を一致させる
- **マスク境界のぼかし**: 合成時の境界ぼかし半径を0〜100 pxで調整し、空と地上をなめらかにブレンドする。0 pxではぼかしを無効にする

### 3.4 画像後処理・補正機能
- **オートストレッチ機能**: リニア画像として合成された結果に対するオートストレッチのみを実装（光害低減などのその他の調整機能は不要）

### 3.5 画像の書き出し
- **出力フォーマット**:
  - **RAW形式 / 16bit リニアDNG (Linear RAW)**:
    - DNG 1.4互換。Adobe製リニアDNGと同じ構成で書き出す
      - **IFD0**: 256px 8bit sRGBサムネイル + DNG共通タグ・埋め込みカメラプロファイル
      - **SubIFD[0]**: 主画像（16bit リニアsRGB, `PhotometricInterpretation=LinearRaw`, `NewSubFileType=0`, 約8MBごとのストリップ分割）
      - **SubIFD[1]**: 長辺1024pxのJPEGプレビュー（`PreviewColorSpace=sRGB`）
      - IFD・XMPをファイル先頭側、画素データを後ろ側に配置する（macOSのFinder/QuickLookはIFDが先頭付近にないと埋め込みプレビューを使わず、サムネイルが真っ黒になるため）
    - **カラー・階調**: スタック結果はトーン処理済みの画像のため、Camera Raw / Lightroom で開いたときにアプリ上の表示と同じ見た目になるよう、無変換の埋め込みプロファイルを使う
      - `UniqueCameraModel` / `ProfileName` は実カメラ名と重ならない固有名（実カメラ名は `Make` / `Model` に保持）とし、Adobeのカメラ別プロファイルが適用されないようにする
      - `ColorMatrix1`（XYZ(D65)→リニアsRGB）、`ForwardMatrix1`（リニアsRGB→XYZ(D50)）、`CalibrationIlluminant1`=D65、`AsShotNeutral`=1,1,1
      - `ProfileToneCurve` を直線（0,0 → 1,1）、`DefaultBlackRender`=None、`BaselineExposure`=0
      - XMPで `crs:CameraProfile`（埋め込みプロファイル名）と `crs:ToneCurveName2012="Linear"` を指定し、「Adobe カラー」等のルックを掛けない
    - **レンズ情報埋め込み**: 基準RAWに紐づくレンズモデル名（`LensModel`）、レンズメーカー（`LensMake`）、焦点距離（`FocalLength`）、F値（`FNumber`）、レンズ仕様（`LensSpecification`）をEXIFタグとして埋め込み
    - **XMPレンズ補正メタデータ**: Adobe Camera Raw / Lightroom 向けに `crs:LensProfileEnable="1"`, `crs:LensProfileSetup="Auto"` を埋め込み、プロファイルはレンズ情報から現像ソフト側で自動選択させる
    - **ExifTool連携**: ExifToolと元RAWが利用可能な場合に、撮影情報（露出・レンズ・日時・GPS）だけを許可リスト方式でコピー。`Orientation`、センサー固有タグ（黒/白レベル・CFA配列等）、メーカーノートはコピーしない（失敗時はネイティブ生成DNGを保持）
  - **16bit TIFF**: 16bit TIFF出力（ExifToolと元RAWが利用可能な場合はメタデータのコピーを試行）
  - **32bit FITS**: 天体写真解析用32bit浮動小数点カラーFITS出力（`NAXIS=3`, `NAXIS3=3`、R・G・Bプレーン順、リニアsRGB 0〜1、`ROWORDER='BOTTOM-UP'`）
  - **高画質JPEG**: プレビュー・Web共有用
- **出力設定**: 保存先ディレクトリの指定、ファイル名の自動採番、レンズプロファイル埋め込みのON/OFF切り替えおよび手動編集

## 4. UI/UX 仕様案
- **1ウィンドウ構成**を採用し、以下のペインで構成します。
  1. **左ペイン（サイドバー）**: ファイルリストおよび画像タイプ別のタブ（Base, Light, Dark等）
  2. **中央ペイン**: 画像プレビュー、およびブラシによるマスク指定エリア
  3. **右ペイン**: 処理設定パラメータ、スタッキング開始ボタン、プログレスバー
- **ダークモード設定**: 夜間や暗い部屋での作業を考慮し、UIはダークトーンを基調とする（macOSのシステム設定連動）。

## 5. 非機能要件
- **動作プラットフォーム**: macOS 14 (Sonoma) 以降（macOS 15.7で検証）
- **アーキテクチャ**: ソースはビルドホストのアーキテクチャ向けにネイティブビルド可能。現在の検証済みDMGはx86_64版（Intel Macネイティブ、Apple Silicon MacはRosetta 2経由）
- **パフォーマンス**:
  - 大量・高画素のRAW画像を扱うためのメモリ使用量の最適化
  - 画像アライメント・合成処理のGPUアクセラレーション（Metalフレームワーク）および高速CPUベクトル演算（Accelerate / vDSP）のハイブリッドフォールバック
- **使用言語・技術スタック**:
  - **フロントエンド（UI層）**: Swift, AppKit (Cocoa / NSWindow / NSViewController / NSTableView / NSSplitView)
  - **画像処理コア層**:
    - 特徴点検出・位置合わせ: C++ / Objective-C++ (OpenCV Wrapper)
    - スタッキング・キャリブレーション: Swift + Accelerate (vDSP) / Metal Compute Shaders
    - メタデータ・レンズプロファイル: CoreGraphics / ImageIO / ExifTool
    - タイムラプス生成: AVFoundation (H.264 / HEVC)

## 6. 主な実装機能一覧
1. **各社RAW画像読み込み**: Sony (.arw), Canon (.cr2/.cr3), Nikon (.nef), Fujifilm (.raf), OM/Olympus (.orf), Panasonic (.rw2), Pentax (.pef), Adobe (.dng)
2. **レンズプロファイル抽出 & DNG埋め込み**: EXIFタグ (`LensMake`, `LensModel`, `FocalLength`, `FNumber`) + Adobe Camera Raw XMP (`crs:LensProfileEnable="1"`)
3. **星空と地上の分離スタッキング**: ブラシツールによる空/地上マスク指定、シームレス合成
4. **高精度アライメント**: OpenCV 特徴点マッチングによる回転・平行移動補正
5. **キャリブレーションフレーム減算**: ダーク・フラット・バイアスフレームのマスター生成と自動減算
6. **タイムラプス動画エクスポート**: FPS/秒数指定、フリッカー除去、オートストレッチ、解像度・コーデック選択
7. **macOS 14以降に対応**: AppKit UI + GCDを使用し、単体・統合テストで主要処理を検証
