MacStarStacker (星景写真用グラフィックツール) - 使い方ガイド

MacStarStackerは、星景写真のノイズ除去（スタッキング）、空と地上の分離合成、そして高度なタイムラプス動画作成を1つのアプリで実現するための専用ツールです。

🖥 動作環境（システム要件）

  • 対応OS: macOS 13.0 (Ventura) 以降
  • アーキテクチャ: Apple Silicon (M1/M2/M3等) 推奨 / Intel Mac対応
  • メモリ (RAM): 8GB 以上必須（高解像度のRAW画像を多数扱う場合は16GB以上を推奨）

📸 対応データ形式

  • 入力フォーマット:
    • RAW画像 ( .dng, .cr2, .cr3, .nef, .arw, .raf など各社フォーマット )
    • 天文用・汎用高画質画像 ( .tiff, .tif, .fit, .fits )
    • 汎用画像 ( .jpg, .jpeg, .png, .heic )
  • 出力フォーマット:
    • スタック画像: 16bit TIFF, 32bit FITS, DNG (RAW), JPEG
    • タイムラプス動画: H.264 (.mp4), H.265/HEVC (.mp4)

💻 1. 基本画面の構成

アプリ画面は大きく3つのパネルに分かれています。

  • 【左】画像ファイルパネル

    • Light: 星が写っているメイン画像群。
    • Dark: センサーノイズ除去用のダーク画像（レンズキャップをして撮影した黒い画像）。
    • Flat / Bias: レンズの周辺減光やセンサーのバイアス補正用画像。
    • ** Base Image (基準画像)**: アライメント（位置合わせ）の基準となる、1枚の特別なLight画像です。Lightのファイルの☆マークで手動選択することもできます。

  • 【中央】プレビュー＆マスク描画パネル

    • 選択した画像のプレビュー、またはスタック・合成結果のプレビューが表示されます。
    • 「空＋地上」合成モードの際には、ここで直接空と地上の塗り分け（マスク）を行います。
    • トラックパッドでピンチイン・アウト（拡大縮小）、ドラッグ（移動）が可能です。ダブルクリックでリセットします。

  • 【右】設定・処理パネル

    • 上部のタブで「スタック」と「タイムラプス」のモードを切り替えます。
    • 処理に関する詳細なパラメータや、書き出しフォーマットの指定を行います。

🌟 2. スタッキング（ノイズ低減合成）の手順

数枚〜数十枚の星空画像を重ね合わせ、ノイズのない滑らかな一枚の画像を作成します。

Step 1. 画像の読み込み

左のファイルパネルの「Light」タブに、処理したい星景画像をドラッグ＆ドロップするか、「＋」ボタンから追加します。 ※必要に応じて Dark / Flat / Bias 画像も追加してください。

Step 2. コンポジットモードの選択

右の【設定・処理パネル】から「コンポジットモード」を選びます。

  • 空・地上: 画像全体を均一に処理します（流星群の比較明合成や、星空単体、地上の風景単体を処理する場合など）。
  • 空＋地上: 空（星）は日周運動に合わせて追尾・合成し、地上は動かずシャープに固定する、星景写真特有の高度な合成を行います。

Step 3. マスクの作成（空＋地上モードの場合のみ）

「空＋地上」モードを選択すると、中央パネルで「マスク描画」機能が有効になります。

  1. 右パネルの「ブラシ」から 空 (青) を選び、星空の部分を塗りつぶします。星が動く軌道全体を余裕を持って大まかに塗りつぶしてください。
  2. 次に 地上 (緑) を選び、動かしたくない地上風景を塗りつぶします。
  3. サイズ と 柔らかさ のスライダーを使い、空と地上の境界部分を自然に馴染むように（柔らかさを高くして）塗ると、より美しい合成になります。
  4. はみ出た場合は「消しゴム」で消すか、「マスクをクリア」ボタンで最初からやり直せます。

Step 4. スタック設定と開始

  1. 必要に応じて「アライメント（位置合わせ）」をONにします（基本はON推奨）。
  2. 出力フォーマット（16bit TIFF 等）を選びます。
  3. 「Start Stacking」 ボタンを押して処理を開始します。
  4. プログレスバーが進行し、完了すると自動的に中央パネルに結果が表示されます。 ※画面下の「スタック結果を非表示」ボタンで、元の画像と結果を見比べることもできます。

🎬 3. タイムラプス動画作成の手順

大量の静止画をつなぎ合わせて、高品質な星空タイムラプス映像（H.264 / HEVC）を書き出します。

Step 1. 画像の準備

スタック時と同様に、左パネルの「Light」タブにタイムラプス化したい全ての画像（連番画像）をドラッグ＆ドロップして追加します。

Step 2. モード切り替え

右パネルの一番上のタブを 「タイムラプス」 に切り替えます。

Step 3. タイムラプス設定

  • フレーム範囲: 長い連番の中の一部だけを動画にしたい場合、開始・終了フレームを指定します。
  • 再生速度:
    • FPS指定: 1秒間に何枚の画像を表示するか（通常は24fpsか30fps）を直接指定します。
    • 動画の長さ（秒）指定: 最終的に「10秒の動画にしたい」などの秒数を指定し、自動でFPSを算出させます。
  • 処理（高度な設定）:
    • アライメント（位置合わせ）: 風や三脚の揺れで生じた微妙なズレを、1枚目の画像（Base Image）を基準にすべて自動で補正してつなぎ合わせます。比較明合成（Star Trails）では星の軌跡を保つため自動的にOFFになります。
    • フリッカー除去 (輝度均一化): 露出のばらつきによる動画の「チラつき」を自動で平滑化します。
    • オートストレッチ: RAWデータや暗い星空画像の明るさ・ガンマを、プレビュー品質に自動で引き上げて動画化します。

Step 4. 書き出し

  1. 一番下の 「タイムラプスの書き出し」 ボタンをクリックします。
  2. 保存先とファイル名（.mp4）を指定するダイアログが出るので決定します。
  3. エンコード処理が非同期で始まり、進捗がテキストで表示されます。バックグラウンドで処理が進むため、完了までしばらくお待ちください。

💡 4. その他の便利機能・Tips

  • 元に戻す（Undo機能）: 上部のメニューバー「編集（Edit）」＞「元に戻す (Undo)」を選択するか Command + Z で、間違えて画像を消してしまった際などに1つ前の操作に戻れます。
  • 画像の個別確認: 左パネルのリストから特定の画像をクリックすると、中央のプレビューにその画像が大きく表示されます。
  • ファイルリストのクリア: 画像タブ名の横にあるゴミ箱ボタンを押すと、そのタブの画像をすべて一括で削除できます。（Light画像を消すと、設定されていた基準画像などのメタデータも自動的に初期化されます）。
